## Stack

- **Framework:** Next.js 16 (App Router) — TypeScript
- **Styling:** Tailwind CSS v4
- **Animation:** Framer Motion + GSAP
- **Fonts:** Inter + Instrument Serif + Geist Mono

## Run locally

```bash
npm install
npm run dev
```
